# Living-garden map artwork

These 24 transparent WebP plants are copied unchanged from version 5 of the
user-provided Site:
https://hanzi-living-garden-19.light-owlet-9049.chatgpt.site/

Source repository commit: 2074b2968cb3764ca0ac86cd1af0a09e50ed79ff

The Site's `plant-generation.json` records these as generated illustrations
based on the user's HanziGarden artwork. The active map also adapts its axial
projection, softly blended terrain, connected ponds, whole-sprite depth ordering,
segmented boundaries and connected-region partitioning. The original prototype
in `src/prototype/HexGardenPrototype.tsx` is not used by the active map.

The reference has 271 cells and 8 biomes. This game retains its original 220
beds, 15 biome identities and all save/progression data. Seven additional
cultures have separate crop silhouettes in `hexGardenRenderer.ts`.
