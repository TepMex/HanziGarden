# Исправления карты сада и боевого экрана

## Кратко

Обновить мобильную навигацию, управление сеткой, отображение зарастания и интерфейс боя. Последняя открытая грядка сохраняется между запусками; на мобильных карта автоматически центрируется на ней с масштабом примерно по ширине экрана.

## Изменения

- Сохранение и камера:
  - Добавить в сохранение `lastActivePlotId`; обновлять его при входе в бой.
  - Поднять версию сохранения до v3 и мигрировать старые данные без потерь: использовать грядку последнего повторённого иероглифа, а при отсутствии истории — первую открытую.
  - При каждом открытии карты на экране до 820 px один раз центрировать последнюю активную грядку и подбирать максимально допустимый масштаб, оставляя около 10% горизонтального отступа.
  - На desktop сохранить текущую камеру и поведение без автофокуса.

- Карта и панель действий:
  - Полностью удалить включение сетки при перетаскивании и pinch-жесте.
  - Показывать сетку исключительно по кнопке `Grid3X3`, расположенной слева от статистики; кнопка всегда без видимой надписи, но с меняющимся `aria-label` и `aria-pressed`.
  - На мобильных показывать кнопку статистики только как `BarChart3`; на desktop оставить надпись.
  - Удалить из шапки оба счётчика: «изучено» и «на повторение».

- Зарастание грядок:
  - Рассчитывать долю по количеству due/new-иероглифов, а не по сумме штрихов.
  - Для открытой грядки применять формулу площади сорного слоя: `0% due → 0%`, `0–30% due → 30%`, `более 30% → фактический процент due`; закрытые грядки оставлять заросшими на 100%.
  - Масштабировать `garden-map_negative.webp` один раз на всю карту и компоновать через единую маску без плиточных кропов. Внешние стороны и углы раскрывать только по правилам раздела 8.1 основной `GAME_SPEC.md`; внешний фон не является безусловно чистым.
  - Создавать стабильные органические пятна через детерминированный low-frequency noise от `plot.seed`, обрезать их по перспективному контуру грядки и слегка смягчать края. Одинаковое состояние сохранения должно давать одинаковую форму пятна.
  - Заменить существующую расширяющуюся reveal-маску новой маской сорного покрытия; убрать ставшую неиспользуемой логику эллиптического раскрытия.

- Боевой экран:
  - Удалить `weed-core` вместе с фиолетовой точкой, анимациями и связанным состоянием урона.
  - Удалить подпись «Целевое значение», сохранив само значение.
  - Для дополнительного значения примитива показывать приглушённую пиктограмму `Plus` и текст значения без слова «Примитив».
  - Удалить правый индикатор штрихов и нижнюю панель с комментариями, ошибками и количеством оставшихся штрихов. Внутренний подсчёт штрихов и ошибок сохранить для Hanzi Writer, фона и FSRS.
  - Оставить кнопку подсказки, индикатор здоровья участка, состав иероглифа и состояния завершения.
  - Сделать внешний `.writing-circle` очень мягким круглым ориентиром. Внутри него разместить невидимый квадратный target Hanzi Writer шириной `70.71%` диаметра круга — углы и границы квадрата визуально не показывать.
  - Ограничить диаметр круга размерами viewport, чтобы рабочий квадрат оставался удобным в portrait и landscape; проверку пересечения подсказки со значением выполнять относительно внешнего круга.

## Интерфейсы и данные

- `SaveGame` v3 получает `lastActivePlotId: string | null`.
- `WorldMap` получает идентификатор грядки для одноразового мобильного фокуса.
- В camera math добавить чистую функцию расчёта камеры по границам грядки, viewport и горизонтальному запасу.
- Добавить чистые функции расчёта доли due-иероглифов и площади сорной маски.

## Проверка

- Unit-тесты миграций v1/v2 → v3, включая выбор последней повторённой и первой открытой грядки.
- Unit-тесты автофокуса: центрирование, горизонтальный запас, ограничения zoom и отсутствие desktop-фокуса.
- Unit-тесты формулы пятен для 0%, 1–30%, 31–99% и 100%, стабильности seed и допустимого отклонения фактической площади маски.
- Browser-регрессии на 320×568, 390×844 и мобильном landscape:
  - обе кнопки доступны и состоят только из пиктограмм;
  - сетка не появляется от drag/pinch и переключается кнопкой;
  - последняя грядка помещается по ширине после запуска и возврата из боя;
  - круг письма не пересекается с prompt и содержит интерактивный квадрат;
  - рисование и подсказка продолжают работать после изменения target;
  - отсутствуют `weed-core`, подписи и оба удалённых индикатора.
- Запустить unit-тесты, lint, production build и существующие проверки battle/map для web и Android `file://`.

## Принятые допущения

- «Последняя активная» означает последнюю грядку, в которую игрок вошёл, даже если не завершил иероглиф.
- Автофокус применяется только при входе на карту на мобильной ширине; последующее ручное перемещение не перехватывается.
- Пятна показывают визуальную долю due/new-иероглифов, а существующий штрих-взвешенный показатель здоровья боя не меняется.
